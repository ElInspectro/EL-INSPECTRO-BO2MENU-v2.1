ElInspectro's BO2 Mod Menu
A custom Black Ops 2 mod menu for Plutonium (T6). Built from scratch for offline / private matches with bots.
> \*"When this menu opens, everyone knows whose lobby it is."\*
Current version: v2.1

Installation
Install and run Plutonium (BO2 / T6). Do not use the Steam version of Black Ops 2.
Download modmenu.gsc from the latest release.
Put it into your Plutonium scripts folder:
```
%localappdata%\\Plutonium\\storage\\t6\\scripts\\mp\\
```
On some installs the folder is:
```
%localappdata%\\Plutonium\\storage\\t6\\raw\\scripts\\mp\\
```
The file must be named exactly modmenu.gsc.
Start a private match and add bots in the lobby.
---
Controls
Open menu: Crouch + Melee
Up / Down: Aim (Right Click) / Shoot (Left Click)
Select: Use (F)
Back / Close: Melee
Noclip / Photo Mode flying: Close menu, hold Left Click
---
Good to know
Bots are set in the private match lobby, the menu controls them.
Some Boss Fight / bot features work best in Free-for-All.
You jump a bit lower when standing on built crates (same as real care packages).
Field of view is changed in Plutonium itself, not in the menu:
```
cg\_fov
```
